ASHIRVAD HOSPITAL KOTLIN ANDROID STARTER

OPEN IN ANDROID STUDIO
1. ZIP extract karo.
2. Android Studio > Open > extracted Ashirvad_Hospital_Kotlin_Android folder.
3. Gradle sync complete hone do.
4. Android emulator create karo, ya USB debugging enabled phone connect karo.
5. Run (green triangle) click karo.

This starter creates a basic Android home screen with the hospital feature list.
It is not connected to the Java backend or database yet. That API integration is a later step.

Requirements:
- Android Studio with compatible Android SDK
- Internet for Gradle dependencies
- JDK bundled with Android Studio / compatible Gradle JDK

IMPORTANT:
Do not store real patient information in this starter app. Add authentication,
secure API communication, role-based access, safe session handling, and privacy
controls before connecting real hospital records.
